# SecurLineUz website

Статический сайт компании SecurLineUz. В репозитории хранится готовый HTML/CSS/JavaScript без backend и без внешних build-зависимостей. GitHub Pages публикует содержимое корня ветки `main`.

## Файлы

- `index.html` — главная страница, каталог оборудования, услуги и контакты.
- `styles.css` и `app.js` — адаптивная верстка, поиск/фильтры каталога и поведение формы.
- `assets/hero.webp` — оригинальный hero-арт.
- `CNAME` — пользовательский домен `adamarket.uz`.
- `robots.txt` и `sitemap.xml` — поисковая индексация.

Цены в каталоге указаны в узбекских сумах за единицу; комплектация и наличие уточняются при подготовке сметы.
