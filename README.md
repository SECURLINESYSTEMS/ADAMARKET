# SecurLineUz

Статический сайт компании SecurLineUz, публикуемый через GitHub Pages на `https://adamarket.uz/`.

## Страницы и файлы

- `index.html` — главная страница, решения, монтажные услуги и контакты.
- `catalog.html` и `catalog.js` — полный каталог с поиском, фильтрами по семи разделам и постраничным просмотром.
- `styles.css` и `catalog.css` — адаптивные фирменные стили.
- `price-list.pdf` — полный прайс в компактном формате для печати.
- `price-list.xlsx` — клиентская таблица с итоговыми ценами; исходные скрытые ценовые поля в файл не включены.
- `assets/hero.webp` и `favicon.svg` — визуальные материалы сайта.
- `robots.txt`, `sitemap.xml` и `CNAME` — индексация и собственный домен.

## Примечания к каталогу

Каталог составлен по прайс-листу от 21.09.2026. В нём представлены позиции с указанной ненулевой ценой; технические характеристики доступны в онлайн-каталоге и таблице Excel. Показанные суммы пересчитаны из USD по курсу 1 USD = 12 055,90 UZS на 17.10.2026. Монтажные расценки опубликованы отдельно и не пересчитаны по этому прайсу. Наличие, количество и состав комплектации уточняются при подготовке предложения.
