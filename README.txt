ADAMARKET Mini App v2
======================

1. Replace the existing index.html in the GitHub repository with this index.html.
2. Keep GitHub Pages on main / root.
3. Open the Mini App from @ADAMARKETuz_bot.

Backend:
https://nmskpqugwiwdcukqckcy.supabase.co/functions/v1/adamarket-api

The backend validates Telegram Mini App initData server-side and uses Supabase for profiles,
favorites, listings and requests. The browser never contains a Supabase secret/service key.

The app also works in demo mode when opened outside Telegram.
