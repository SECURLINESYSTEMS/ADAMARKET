ADAMARKET Mini App — загрузка фотографий

1. Замените index.html в репозитории ADAMARKET-miniapp.
2. Commit changes.
3. Подождите 1–2 минуты, пока GitHub Pages обновится.
4. Закройте и заново откройте Mini App в Telegram.

Теперь при добавлении объявления можно выбрать до 5 фотографий прямо с телефона.
Фотографии автоматически сжимаются и сохраняются в Supabase Storage.
