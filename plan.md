# ADAMARKET — план бесплатной бета-платформы

## Цель

Собрать аудиторию в Ташкенте без оплат: каталог рекламных мест, бесплатные объявления, поиск, AI-помощник и базовая модерация. Платежи, продвижение и платные тарифы намеренно не реализуются до регистрации ООО и подключения лицевого счёта.

## Архитектура

- `index.html` — мобильный тёмный интерфейс ADAMARKET, языки RU/UZ/EN.
- `server.py` — временный бесплатный backend для публичной беты: HTTP API, SQLite и раздача статических файлов.
- `adamarket.db` — общая база объявлений, заявок, событий и настроек; секреты в файл не записываются.
- `assets/` — фирменный фон Ташкента и 3D-иконки.
- `offer.html`, `privacy.html` — рабочие юридические документы с реквизитами владельца.
- `manus-routes.json` — публичные маршруты preview.

## Основные функции этапа

1. Публичный каталог: объявления со статусом `approved` видны всем.
2. Бесплатное размещение: пользователь отправляет объявление без оплаты; оно получает статус `pending` и после базовой модерации становится видимым.
3. Лимит беты: одно бесплатное объявление в месяц на email/телефон при наличии данных; для гостевого демо действует антиспам-ограничение.
4. Поиск и фильтры: текст, район, тип и цена.
5. AI-помощник: отвечает по каталогу и помогает сформулировать запрос; не выдумывает несуществующие места и сообщает, когда данных недостаточно.
6. Связь: заявка владельцу без раскрытия личных данных в публичной карточке.
7. Модерация: pending/approved/rejected, жалобы и скрытие объявления.
8. Языки: RU/UZ/EN для основных экранов.
9. Никаких платежей: в UI и API отсутствуют покупка, тарифы, продвижение и платёжные реквизиты.

## Дизайн

- **Движение:** premium dark marketplace.
- **Принципы:** доверие через реальные фото Ташкента, высокая читаемость, быстрый путь к объявлению, мягкая неоновая подсветка.
- **Палитра:** глубокий navy как фон доверия, electric blue для действия, cyan для AI и ссылок.
- **Композиция:** hero-карточка, быстрые роли, категории, топ объявлений и фиксированная нижняя навигация.
- **Характер:** полезный, локальный, профессиональный.

## Безопасность

- Секрет AI остаётся только на сервере.
- Пользовательские поля экранируются на frontend/backend.
- Максимальный размер JSON и длина строк ограничены.
- Публичный каталог отдаёт только approved-объявления.
- Временная beta-база не является заменой production-бэкенду; после стабилизации переносится в Cloudflare D1/R2.
